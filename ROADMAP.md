- [x] **ЭТАП 2: Автономный Go-Агент (REST API)**
  - Реализация Go-агента без сторонних dependencies (`Agent/main.go`, `agent.exe`).

  - Python-резерв (`agent.py`) и фолбэк в `bin/agent.bat`.

- [x] **ЭТАП 3: Автосбор диагностики и Генерация Отчетов**
  - Модуль `gatherDiagnostics()` (PowerShell: ОС, CPU, RAM, диски, IP, Event Log).
  - Полный дамп в `Data/logs/sysinfo_<SessionID>.txt`, срез — первым сообщением в Gemini.
  - Спецкоманда `/diag` для обновления снимка системы.
  - Спецкоманда `/report` для генерации итогового Markdown-отчета.

- [x] **ЭТАП 4: Пульт управления и Интеграция**
  - Единое консольное меню `START.bat`.
  - Прямой вызов `agent.exe` без разрыва консольного окна (единый I/O контекст).
  - Запуск Firefox Portable через изолированный профиль `bin/ff-portable.bat`.
  - Быстрый переход к артефактам `Data/reports` и `Data/logs`.
