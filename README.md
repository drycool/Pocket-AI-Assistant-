# Pocket AI Assistant (USB Portable Edition)

[![Release](https://img.shields.io/github/v/release/drycool/Pocket-AI-Assistant-)](https://github.com/drycool/Pocket-AI-Assistant-/releases/latest)

> **Скачать готовый `agent.exe` без компиляции:** [последний релиз](https://github.com/drycool/Pocket-AI-Assistant-/releases/latest/download/agent.exe)

Автономный портативный комплекс для выездных системных администраторов, сервисных инженеров и IT-специалистов. Предназначен для быстрой экспресс-диагностики, поиска неисправностей и устранения сбоев на гостевых ПК под управлением Windows прямо с USB-флешки.

В основе агента — высокопроизводительный бинарник на **Go** (без внешних зависимостей) с **мультипровайдерной LLM-архитектурой**: единой абстракцией `sendMessage` поверх OpenAI-совместимого `REST API` (`/v1/chat/completions`) и нативного клиента Gemini, с автоматическим fallback между провайдерами при лимитах (429/503) или недоступности сети. Метрики Windows собираются через PowerShell, итоговые инженерные отчеты генерируются в формате **Markdown**.

---

## Ключевые возможности

- **Полная портативность** — работает из любой директории и с любого USB-накопителя без установки и прав администратора (для базового диалога).
- **Компактность и автономность** — исполняемый файл `agent.exe` весит ~7.5 МБ (компиляция с флагами оптимизации `-ldflags="-s -w"`).
- **Чистый Go (Native REST Client)** — без сторонних библиотек и тяжелых фреймворков. Используются только стандартные пакеты Go (`net/http`, `os/exec`, `encoding/json` и др.).
- **Мультипровайдерность и самовосстановление** — приоритетный список провайдеров в `Data/config.json`; единая функция `sendMessage` сама переключается на следующий источник при ошибке `429`/`503` (лимит) или сетевой недоступности. Поддержка DeepSeek, Groq, OpenRouter, Together AI, локальных Ollama/vLLM/llama.cpp и нативного Gemini.
- **Автоматическая экспресс-диагностика** — модуль `gatherDiagnostics()` за 1–2 секунды собирает сведения об ОС, CPU, RAM, дисках, сетевых интерфейсах/IP и проверяет Windows Event Log на критические ошибки (System Log, Level 1,2).
- **Атомарная запись сессий** — сохранение истории через схему `.tmp` + `os.Rename` для защиты JSON от повреждений при неожиданном извлечении флешки.
- **Корректный контекст LLM** — системные инструкции передаются отдельным объектом (`system_instruction` для Gemini, `messages[0].role=system` для OpenAI-совместимых) и не засоряют историю.
- **Генератор отчетов (`/report`)** — модель анализирует всю историю диагностики и формирует структурированный технический отчет в `Data/reports/REPORT_<SessionID>.md`.
- **Python-резерв** — альтернативный скрипт `agent.py` на случай отсутствия скомпилированного `agent.exe`.


## Быстрый старт

### Требования

- **ОС:** Windows 7 / 8.1 / 10 / 11 / Server 2012+ (x64)
- **Сеть:** доступ к выбранному LLM-провайдеру (HTTPS / 443). Примеры эндпоинтов:
  - `Gemini` — `generativelanguage.googleapis.com`
  - `DeepSeek` — `api.deepseek.com`
  - `Groq` — `api.groq.com`
  - `OpenRouter` — `openrouter.ai`
  - `Local-Ollama` — любой хост в Tailscale/LAN (без внешнего интернета)
- **API-ключи:** чтобы включить fallback и дешёвые платные провайдеры, заполните список `providers` в `Data/config.json`.

### Приоритетный список провайдеров (`Data/config.json`)

Агент вызывает провайдеров по порядку списка — первый успешный ответ возвращается. При `429`/`503` (лимит) или отсутствии сети запрос автоматически уходит на следующий источник.

```json
{
  "providers": [
    { "name": "Gemini-Free",      "type": "gemini", "api_key": "AIzaSy...", "model": "gemini-2.5-flash" },
    { "name": "DeepSeek-Paid",    "type": "openai", "base_url": "https://api.deepseek.com/v1", "api_key": "sk-ds-...", "model": "deepseek-v4-flash" },
    { "name": "OpenRouter-Paid",  "type": "openai", "base_url": "https://openrouter.ai/api/v1", "api_key": "sk-or-...", "model": "anthropic/claude-3.5-haiku" },
    { "name": "Groq",             "type": "openai", "base_url": "https://api.groq.com/openai/v1", "api_key": "gsk_...", "model": "llama-3.3-70b-versatile" },
    { "name": "Local-Ollama",     "type": "openai", "base_url": "http://100.x.y.z:11434/v1", "api_key": "ollama", "model": "qwen2.5-coder" }
  ]
}
```

- `type`: `"gemini"` (нативный `generateContent`) или `"openai"` (стандарт `/v1/chat/completions` — DeepSeek, Groq, OpenRouter, Together AI, Ollama, vLLM, llama.cpp).
- Если `config.json` отсутствует, агент предложит ввести ключ и создаст одиночного провайдера `Gemini-Free`.
- Для локального Ollama достаточно передать `"api_key": "ollama"` — ключ не проверяется.

### Запуск с флешки

1. Вставьте USB-накопитель в целевой ПК.
2. Запустите `START.bat` в корне флешки.
3. В меню выберите пункт **[1] Запустить Go-Агент**.
4. (По желанию) заполните `Data/config.json` списком провайдеров (см. выше).
5. Подтвердите автодиагностику при создании новой сессии.

## Интерактивные команды агента

| Команда | Описание |
|---------|----------|
| `/diag` | Повторный сбор системных метрик и отправка обновленного дампа модели |
| `/report` | Анализ всей сессии и формирование итогового отчета в `Data/reports/` |
| `exit` / `quit` | Сохранение истории сессии и корректное завершение работы |

## Сборка из исходников

Компиляция под Windows (например, из-под Linux/macOS или другой машины разработки):

```bash
cd Agent
GOOS=windows GOARCH=amd64 go build -ldflags="-s -w" -o agent.exe main.go
```

При успешной сборке размер `agent.exe` составит ~7.5 МБ.

## Пример отчета (`/report`)

Файл `Data/reports/REPORT_<SessionID>.md`:

```markdown
# Отчет о диагностике и ремонте ПК
**Сессия:** 2026-08-11_15-04_Work-PC
**Дата:** 2026-08-11 15:10

## 1. Первичные симптомы и обращение
Клиент обратился с жалобой на медленную работу системы и падение сетевого соединения.

## 2. Результаты автодиагностики и выявленные проблемы
- **CPU:** Intel Core i5-10400 @ 2.90GHz
- **RAM:** доступно 1.2 GB из 16 GB (высокое потребление)
- **Event Log:** ошибки EventID 10016 (DistributedCOM) и сбои службы DNS Client

## 3. Выполненные действия и команды
1. Сброс сетевого стека: `netsh winsock reset`
2. Очистка кэша DNS: `ipconfig /flushdns`
3. Оптимизация автозагрузки через PowerShell

## 4. Итоговый статус и рекомендации
Сетевое соединение стабильно. Рекомендовано увеличить свободное место на диске C: и провести Chkdsk.
```

## Безопасность и конфиденциальность

В репозиторий включен `.gitignore`, предотвращающий случайную публикацию персональных данных и API-ключей:

```gitignore
# Конфигурации и ключи
Data/config.json

# Данные сессий и дампы систем
Data/sessions/*.json
Data/logs/*.txt
Data/reports/*.md

# Исполняемые файлы и артефакты Python
*.exe
*.pyc
__pycache__/
```

> Примечание: бинарники (`agent.exe`) исключены из версионного контроля. Для готового «портативного комплекта» соберите `agent.exe` локально (см. раздел «Сборка») или возьмите из релиза.
